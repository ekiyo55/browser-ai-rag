# AI サービスへの登録

どのサービスでも、やることは「MCP サーバーの URL（`https://…/mcp`）を登録して、許可する」だけです。画面の名前や場所はよく変わるので、ここには確かめた日付を書いておきます。

| サービス | 登録する場所 | 条件 | 確認日 |
|---|---|---|---|
| Claude | 設定 → コネクタ → カスタムコネクタを追加 | 無料プランは1つまで | 未 |
| ChatGPT | 設定 → アプリとコネクタ → 詳細設定で開発者モードをオン → 作成 | 有料プラン | 未 |
| Gemini | 設定 → 接続済みアプリ → カスタムアプリ（Web版のみ） | 個人は AI Pro/Ultra かつ米国。Enterprise はプレビュー | 未 |
| Perplexity | 設定 → Connectors → Custom connector → Remote | Pro / Max / Enterprise | 未 |
| Mistral Le Chat | コネクタ → カスタム | 全プラン | 未 |
| Claude Code / Cursor / VS Code | 各ツールの MCP 設定に URL を書く | — | 未 |

第5〜19章の段階では認証を付けていないので、登録時の認証は「なし」を選びます。第20章で OAuth を付けたら、ここも書き換えます。

認証なしのサーバーは、URL を知っている人なら誰でも呼べます。トンネルは使い終わったら止めてください。
