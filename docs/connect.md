# AI サービスへの登録

どのサービスでも、やることは「MCP サーバーの URL（`https://…/mcp`）を登録して、許可する」だけです。画面の名前や場所はよく変わるので、確かめた日付を書いておきます。本と食い違っていたら、こちらを信じてください。

| サービス | 登録する場所 | 条件 | 確認日 |
|---|---|---|---|
| Claude | 設定 → コネクタ → 追加 → カスタムコネクタを追加 | 無料プランは1つまで。組織プランは管理者が配れる | 2026-10-06（実機） |
| ChatGPT | プラグイン → 追加 → カスタム MCP サーバーを作成 → プラグインとして作成 | 有料プラン（Go で確認） | 2026-10-06（実機） |
| Gemini | 設定 → 接続済みアプリ → カスタムアプリ（Web 版のみ） | 個人は米国・18歳以上・個人アカウント・英語のみ。Enterprise／Business は管理者 | 2026-10-06（各社の説明） |
| Perplexity | 設定 → Connectors → Custom connector | Pro / Max / Enterprise | 2026-10-06（各社の説明） |
| Mistral Le Chat | コネクタ → カスタム | 各プラン（ワークスペースの管理者が追加） | 2026-10-06（各社の説明） |
| Grok | grok.com/connectors → New Connector → Custom | — | 2026-10-06（各社の説明） |
| Microsoft 365 Copilot | 管理センターで MCP のコネクタを作成 | 組織の管理者 | 2026-10-06（各社の説明） |
| Claude Code / Cursor / VS Code | 各ツールの MCP 設定に URL を書く（第8章） | — | — |

ログインを付けたサーバー（第17章以降）では、登録のときに認証で OAuth を選び、出てきたログイン画面でユーザー名とパスワードを入れます。

ログインを付けていないサーバーは、URL を知っている人なら誰でも呼べます。トンネルは使い終わったら止めてください。
